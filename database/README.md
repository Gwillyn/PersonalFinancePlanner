# Database Design

This folder contains the initial database design for the Personal Finance Planner Web Application.

## Files

- `personal-finance-planner-erd-v1.png` – Visual Entity Relationship Diagram
- `personal-finance-planner-erd-v1.dbml` – Editable dbdiagram.io source file

## Initial Database Tables

The proposed database contains the following tables:

- users
- income_sources
- categories
- recurring_expenses
- budget_plans
- budget_allocations
- savings_goals

The database supports user accounts, recurring income, regular expenses, monthly financial plans, budget allocations, and savings goals.

This is the preliminary database design for Assignment 1 and may be refined during later development phases.
